## 一、 现状诊断：前任 Agent 到底漏改/错改了什么？

1. **【P0 严重错误】滚轮与触控板事件在 `PlayerHUDView` 中被强行拦截吞噬，`VideoView` 的触控板水平滑动精准 Scrubbing 彻底沦为死代码！**

   - **问题根因**: `PlayerHUDView.setupMouseMonitor()` 使用 `NSEvent.addLocalMonitorForEvents` 监听了 `.scrollWheel`，并在第 746 行直接 `return nil` 吞掉了所有滚轮/触控板事件！导致底层 `Sources/SilkPlayer/VideoView.swift`（第 134~205 行）精心实现的 `scrollWheel(with:)`（双指上下调音量、双指左右平滑拖拽进度条 Scrubbing）**永远收不到任何事件**！
2. **【P0 严重错误】顶栏“图钉（窗口置顶）”按钮与菜单栏“浮动在最前 (Float on Top)”状态源分裂、互相打架！**
   - **现状代码**:
     - `Sources/SilkPlayer/PlayerHUDView.swift` 第 212~221 行：顶栏图钉按钮读写的是 `AppSettings.shared.keepWindowOnTop`。

   - **问题后果**: 用户从菜单栏开启/关闭置顶后，顶栏图钉图标状态完全不变；再去点顶栏图钉按钮时，需要连点两次才能响应。
3. **【P1 严重交互错误】顶栏双击区域（`isTopBarArea`）高度写死为 `44pt`（实际顶栏在 `30pt~60pt`），且在 HUD 隐藏时依然强占画面顶部双击！**
   - **现状代码**: `Sources/SilkPlayer/VideoView.swift` 第 296~327 行 & `PlayerHUDView.swift` 第 96 行。
   - **问题根因**:
     1. **坐标严重错位**: 在窗口模式下，`PlayerHUDView` 的 `topBar` 设置了 `.padding(.top, 30)`，高度为 `30pt`，因此顶栏胶囊（规格徽章、视频标题、置顶/属性/关闭按钮）实际位于距离窗口顶部 **`30pt ~ 60pt`** 的位置（即 `loc.y` 在 `b.height - 60` 到 `b.height - 30` 之间）。但 `VideoView.swift` 第 296 行却写死 `let isTopBarArea = (loc.y >= b.height - 44.0)`！导致顶栏下半部分（`44pt ~ 60pt`）根本不在 `isTopBarArea` 内——用户双击顶栏标题下半截想最大化窗口（`toggleMaximize`），却误触发了画布双击（直接进了全屏 `toggleFullscreen`）！
     2. **HUD 隐藏时误拦截**: 当 HUD 和顶栏已经自动隐藏（`player.isHUDVisible == false`，纯画面观影态）时，用户在窗口顶部双击原本想切换全屏（或执行设定的 `doubleClickAction`），结果因为 `isTopBarArea` 没有检查 `player.isHUDVisible`，在窗口模式下被强行路由成了 `toggleMaximize`（窗口最大化而非全屏）；而在全屏模式下即使把 `doubleClickAction` 设为了“播放/暂停”，双击画面顶部 44pt 也会被强行退出全屏！
4. **【P1 交互 Bug】在底部控制栏（`loc.y <= 112`）空白间隙按住鼠标拖动，会把整个播放器窗口拖走！**
   - **现状代码**: `Sources/SilkPlayer/VideoView.swift` 第 347~373 行。
   - **问题根因**: `mouseDown` 在 `loc.y <= 112.0`（底部控制栏区域）没有提前拦截返回，而是记录了 `dragInitialMouseScreenLocation`；当用户在进度条或底部按钮附近手滑拖动超过 `3pt` 时，`mouseDragged` 直接触发 `window.performDrag(with: event)` 把整个窗口拖跑了！
5. **【P1 行业惯例缺失】鼠标正悬停在底部控制栏、顶栏或打开右侧抽屉时，1.8 秒不动鼠标，HUD 和鼠标指针竟然直接在手底下消失！**
   - **现状代码**: `Sources/SilkPlayer/PlayerHUDView.swift` 第 832~855 行 & `Sources/SilkPlayer/PlayerCore.swift` 第 1296~1304 行。
   - **问题根因**: 两个 1.8s 定时器（`idleTask` 与 `hudAutoHideTimer`）只判断了 `!player.isScrubbing`，**完全没有判断鼠标当前是否正悬停在顶部控制栏（`topBar`）/ 底部控制栏（`bottomControls`）上，也没有判断右侧播放列表/属性抽屉（`isPlaylistDrawerVisible || isInspectorVisible`）是否正处于打开状态**。用户刚把鼠标移到底部准备点音轨/字幕或看播放列表，停顿 1.8 秒整个控制栏和鼠标光标就消失了，严重违反 IINA / QuickTime / MPV 行业标准。
6. **【P2 交互缺失】空闲主页（`EmptyPlaybackView` 未加载视频时）双击窗口顶栏无法最大化/缩放窗口，且点击即触发 `performDrag` 吞掉双击事件！**
   - **现状代码**: `Sources/SilkPlayer/Player/EmptyPlaybackView.swift` 第 198~202 行。
   - **问题根因**: `WindowDragCanvasView` 在 `mouseDown` 中无条件执行 `window?.performDrag(with: event)`，导致在空闲窗口下双击顶部标题栏无法触发 `toggleMaximize`。
7. **【P2 代码残留】`PlayerCommands.swift` 菜单栏仍残留已废弃的“画面微调（锐化/对比度/亮度）”与“音频延迟”空壳菜单！**
   - **现状代码**: `Sources/SilkPlayer/App/PlayerCommands.swift` 第 207~219 行（Audio Delay）、第 325~349 行（Picture Adjustments）。这些在内核中并无实际 DSP/Shader 接线，应在菜单栏中一并隐藏或移除。

### 任务 5：修复空闲主页（`EmptyPlaybackView.swift`）顶栏双击缩放与拖拽手势
- **文件**: `Sources/SilkPlayer/Player/EmptyPlaybackView.swift`
- **修改位置**: `WindowDragCanvasView`（第 198~202 行）
- **具体改法**:
  将原本粗糙的 `mouseDown` 立即 `performDrag` 改为支持双击最大化与 `3pt` 阈值拖拽：
  ```swift
  public final class WindowDragCanvasView: NSView {
      private var initialMouseLocation: NSPoint = .zero

      override public func acceptsFirstMouse(for event: NSEvent?) -> Bool {
          return true
      }

      override public func mouseDown(with event: NSEvent) {
          guard let window = self.window else { return }
          if event.clickCount == 2 {
              let loc = self.convert(event.locationInWindow, from: nil)
              if loc.y >= bounds.height - 52.0 {
                  PlayerWindowManager.shared.toggleMaximize(window: window)
              } else if AppSettings.shared.doubleClickAction == .openFile {
                  PlayerWindowManager.shared.openFilePicker()
              }
              return
          }
          initialMouseLocation = NSEvent.mouseLocation
      }

      override public func mouseDragged(with event: NSEvent) {
          guard let window = self.window, !window.styleMask.contains(.fullScreen) else { return }
          let current = NSEvent.mouseLocation
          if hypot(current.x - initialMouseLocation.x, current.y - initialMouseLocation.y) > 3.0 {
              window.performDrag(with: event)
          }
      }
  }
  ```
