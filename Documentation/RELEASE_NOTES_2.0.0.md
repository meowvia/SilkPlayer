# SilkPlayer Pro 2.0.0 发布说明 / Release Notes

## 中文版 (Chinese)

### 版本概括
SilkPlayer Pro 2.0.0 是面向影音爱好者的重大版本升级。在保持极简、低资源占用与高画质播放体验的基础上，2.0.0 引入了完整的局域网媒体库、海报墙刮削、独立音乐模式以及多声道离散直通，为本地片库与音乐收藏提供一体化管理与播放体验。

### 核心特性
- SMB 与 NFS 局域网媒体库：原生集成 SMB 2/3 与 NFS 协议，自动发现局域网共享，支持免密码记住凭据与断网自动重连。
- 海报墙与智能刮削：支持智能元数据匹配与海报、演职员表、评分抓取，内置国内直连解析与本地 .nfo 离线文件读取。
- 双栏影视详情与分季选集：提供大图背景、剧集分季横滑选集与多版本画质标签自动提取。
- 独立折叠音乐模式：支持独立迷你播放条与完整专辑队列自由切换，支持无损音频解码、内嵌与外挂歌词同步滚动。
- 5.1 与 7.1 多声道 LPCM 直通：支持 HDMI 与外接多声道音频设备离散直出，精准映射各物理声道。
- 四套全局原厂主题：提供深灰、冰蓝、暖白、青瓷四款界面色彩方案。
- iCloud 观看进度同步：跨 Mac 设备自动同步观影断点与剧集已看标记，支持按需关闭。

### 系统要求
- 最低系统：macOS 14.0 (Sonoma) 或更高版本（完整兼容 macOS 15 Sequoia）。
- 硬件支持：Apple Silicon (M1/M2/M3/M4/M5/M6) 及搭载硬件解码器的 Intel Mac。

## English

### Overview
SilkPlayer Pro 2.0.0 is a major milestone release designed for home theater and audio enthusiasts. Building on SilkPlayer's lightweight Metal-accelerated playback engine, 2.0.0 brings seamless local network media libraries, poster wall scraping, an independent Music Mode, and discrete multichannel LPCM passthrough.

### Key Features
- SMB and NFS Network Libraries: Native SMB 2/3 and NFS client support with auto-discovery, persistent keychain credentials, and resilient reconnects.
- Poster Wall and Smart Scraping: Automated metadata fetching with poster art, cast lists, ratings, direct scraper endpoints, and local .nfo offline parsing.
- Dual-Column Media Details: Rich backdrop presentations, multi-season episode carousels, and automated media badge detection.
- Dedicated Music Mode: Seamless transition between compact status player and expanded queue view with synchronized lyrics and lossless codec support.
- 5.1 and 7.1 Multichannel LPCM Passthrough: Discrete uncompressed audio routing over HDMI and multichannel interfaces.
- Four Studio Themes: Dark Charcoal, Ice Blue, Warm Ivory, and Celadon.
- iCloud Watch Progress Sync: Effortlessly resume playback across your Mac devices.

### System Requirements
- Minimum OS: macOS 14.0 (Sonoma) or later (fully tested on macOS 15 Sequoia).
- Architectures: Apple Silicon (M1-M6) and Intel 64-bit processors.
