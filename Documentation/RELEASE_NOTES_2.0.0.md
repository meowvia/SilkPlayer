# SilkPlayer 2.0.0 版本更新说明 / Release Notes

## 版本概括 / Overview

SilkPlayer 2.0.0 是自项目发布以来规模最大的里程碑更新，标志着播放器正式迈入全新的 2.x 时代。

本次版本核心聚焦专业版（Pro Edition）的全面功能跃升，重磅引入了面向局域网与本地存储的影视媒体库系统，支持局域网服务快速自动发现、本地 .nfo 与免代理元数据解析、沉浸式双栏影视详情页与智能推荐算法；同时深度打造了专属独立音频播放器，提供两段式自由折叠播放模式、状态栏微型播控与全格式无损高清音频回放。

关于免费版（Standard Edition）：基础播放核心持续保持完全免费且开源，不设任何强制付费弹窗或基础功能阉割；本次更新同步为免费版带来了 Cmd+F 拼音搜索、字幕深度递归关联、纯透明悬浮播控栏、DTS/TrueHD 软限幅下混以及标准音频独立播放等大量核心体验改进。

SilkPlayer 2.0.0 marks the largest milestone release since the project's inception, advancing the player into the new 2.x era.

This release focuses on delivering a comprehensive feature leap for the Pro Edition, introducing a LAN and local media library with zero-config network share auto-discovery, local .nfo and edge metadata scraping, an immersive two-column media detail view, and smart contextual recommendations. Simultaneously, it debuts a dedicated independent audio player featuring a collapsible two-stage interface, status bar micro-control, and full-format lossless HD audio optimizations.

Regarding the Standard (Free) Edition: The core playback engine remains permanently free and open-source under LGPL-3.0 with zero mandatory paywalls or feature compromises. This release simultaneously delivers extensive enhancements to the free edition, including Cmd+F Pinyin playlist search, deep recursive subtitle loading, a transparent floating HUD, DTS/TrueHD soft-knee limiter downmixing, and decoupled standard audio playback.

## 专业版核心特性 / Pro Edition Features

### 1. 原生局域网与本地影视媒体库 / Native LAN & Local Media Library
- **免挂载网络服务自动发现 (Zero-Config Network Auto-Discovery)**:
  内置原生局域网协议栈，无需在系统访达中手动挂载磁盘，即可自动扫描发现局域网内的存储设备（全面支持 SMB 2/3 与 NFS 协议），实现局域网与本地媒体资源秒级识别与即点即播。
  Built-in native network protocol stack automatically discovers storage devices across local shares (fully supporting SMB 2/3 and NFS) without manual Finder mounting, enabling instant playback across local and remote sources.
- **本地 .nfo 离线解析与免代理刮削 (Local .nfo Parsing & Offline Metadata)**:
  内置轻量宽松 XML 解析引擎，深度兼容 Kodi、Jellyfin、Emby 及 TinyMediaManager 生成的标准 `.nfo` 元数据文件；即使在完全离线或无外网 API 环境下，依然能够自动提取剧情简介、上映年份、社区评分与分类标签，并结合 Cloudflare 边缘代理实现毫秒级海报检索。
  Features an integrated resilient XML parser compatible with standard `.nfo` files generated by Kodi, Jellyfin, Emby, and TinyMediaManager, instantly extracting plot outlines, release years, ratings, and tags in completely offline environments.
- **单行紧凑工具栏与批量管理运维 (Compact Header & Batch Operations)**:
  重构顶栏工具布局为单行紧凑模式，回收 36pt 垂直可视面积；提供多选批量管理模式，支持批量重置播放断点、移出媒体库（仅删索引缓存），以及附带废纸篓二次防呆确认的源文件彻底删除。
  Re-architected header layout into a compact single-line toolbar, recovering 36pt of vertical viewport space; introduces a batch management bar supporting bulk checkpoint resets, indexing removal, and trash-protected source file deletion.
- **在架分季切集与 iCloud 进度云同步 (Season Switcher & iCloud Sync Control)**:
  多季连续剧集自动归拢聚合，提供轻量在架切集抽屉（Season Switcher）与逐集独立进度记忆；「设置 -> 局域网」新增「iCloud 跨设备播放同步」总开关与一键「清空云端播放进度」控制，充分保障用户隐私与多设备进度接力。
  Multi-season series are aggregated into structured cards with an episode selection drawer and per-episode checkpoint tracking; Settings adds an iCloud multi-device sync toggle alongside an explicit cloud cache purge action.

### 2. 沉浸式双栏影视详情页与智能关联推荐 / Immersive Detail View & Recommendations
- **双栏响应式详情与毛玻璃环境光 (Two-Column Responsive Detail View)**:
  单击海报卡片即可平滑切入全景影视详情页，具备自适应毛玻璃背景环境光照、2:3 高清海报立体投影、TMDB 社区评分、多季选集大网格，以及分辨率、色彩空间（HDR10 / 杜比视界）、音频规格与文件体积的完整规格徽章。
  Clicking any media card navigates to an immersive full-window detail layout featuring ambient background lighting, 2:3 poster drop-shadow projection, community ratings, episode grids, and comprehensive technical badges (resolution, HDR10/DV, audio channels, and file size).
- **多维加权智能关联推荐引擎 (Smart Contextual Recommendation Engine)**:
  内置基于 Jaccard 流派相似度、系列作品关联、历史观影偏好与评分年代等多维加权算法，在详情页右侧实时推荐 6-8 部同类精彩片源，并严格剔除同名及自身同源分集，杜绝推荐内容自我污染。
  An integrated multi-factor recommendation engine combining Jaccard genre similarity, franchise associations, and rating-era weighting recommends 6-8 relevant titles while strictly filtering out duplicate franchise segments.
- **微型快播与原生自适应几何视窗 (Micro-Play & Adaptive Window Geometry)**:
  海报卡片右上角配备 24x24pt 半透明微型播放键实现单点直达；播放器与媒体库物理层级完全解耦，播放时窗口 100% 独占给视频渲染并自动等比吸附片源画幅，右上角配备毛玻璃 [返回] 胶囊按钮，交互清晰明确。
  Posters feature a 24x24pt semi-transparent quick-play button for direct launch; playback and media library layers are strictly decoupled so the player window adapts natively to the video's exact aspect ratio without pillarboxing.

### 3. 独立音频播放器与全格式无损回放 / Dedicated Audio Player & Lossless Codecs
- **双形态自由折叠视窗 (Two-Stage Morphing Window)**:
  提供专属独立音乐播放界面，支持在 188pt 极简卡片与 420pt 展开播放队列之间平滑折叠切换，贴合桌面随手摆放与多任务分屏需求。
  Offers a dedicated music window that smoothly toggles between a 188pt minimal compact card and a 420pt expanded playlist queue, tailored for desk placement and split-screen multitasking.
- **全格式无损高清音频解析与多声道直通 (Full Lossless Codecs & 5.1/7.1 LPCM)**:
  原生支持 FLAC、APE、WAV、DSD、DTS-CD、TrueHD 等各类高清无损音频格式解析；CoreAudio 渲染管线直接适配多声道 LPCM（5.1 / 7.1）离散直通输出，杜绝立体声强制压缩带来的空间声场损失。
  Native decoding for FLAC, APE, WAV, DSD, DTS-CD, and TrueHD; CoreAudio pipeline natively outputs discrete multichannel LPCM (5.1 / 7.1) without forced stereo downmixing, preserving spatial depth.
- **拟物黑胶与动态音频呼吸光环 (Acoustic Vinyl & Dynamic Visualizer)**:
  内置基于物理角速度模拟的匀速旋转黑胶视窗，联动音轨低频、中频与高频动态能量，实时驱动外层自适应声学光环。
  Features an inertia-simulated rotating vinyl disc coupled with a multi-band dynamic acoustic halo driven in real time by bass, mid, and treble audio levels.
- **菜单栏常驻微型播控与 Dock 零驻留 (Menu Bar Micro-Controller & Zero Dock Footprint)**:
  支持将音乐播放器一键隐匿至 macOS 顶部菜单栏，彻底释放 Dock 栏空间；点击菜单栏图标即可原地呼出悬浮控制面板与歌词信息。
  Enables seamless minimization to the macOS menu bar with zero Dock footprint; clicking the menu bar icon instantly reveals a lightweight floating playback capsule and lyrics.

### 4. 全局四色视觉主题矩阵 / 4-Theme Color Matrix
- **全新 Pro 视觉主题体系 (New Pro Visual Themes)**:
  提供深灰、冰蓝、暖白、青瓷 4 套高对比度主题，全局联动主界面、播放视窗、媒体库与偏好设置，无论深色还是浅色环境均能保持舒适清晰的阅读体验。
  Offers 4 high-contrast themes (Dark Gray, Ice Blue, Warm White, Celadon) synchronized across the main window, player HUD, media library, and Settings, ensuring legible viewing in both light and dark environments.

### 5. 引擎全生命周期资源优化 / Resource Footprint Optimization
- **海报缓存配额管控**: 注入 250 张 / 120MB 硬性内存上限，并按像素字节精确开销淘汰，杜绝大库浏览内存无上限上涨；
- **毛玻璃环境光次采样**: 详情背景毛玻璃强制以 120px 降采样绘制，纹理显存占用降低 90%，杜绝全屏模糊导致的瞬时 GPU 峰值；
- **SQLite 内存主动归还**: 扫库完成后主动调用 `PRAGMA shrink_memory` 归还系统驻留内存，静态浏览维持 0% GPU 损耗与极低 CPU 负载（<0.5%）。

## 免费版基础能力增强 / Standard Edition Enhancements

- **播放列表 Cmd+F 拼音即时搜索 (Multimodal Instant Search & Pinyin Matching)**:
  播放列表内置即时过滤，支持文件名原文字符匹配以及完整中文拼音首字母过滤，海量分集秒级定位。
- **外挂字幕 Subs 目录深度递归检索 (Deep Recursive Subtitle Detection)**:
  自动递归扫描影视同级及 `Subs/`、`Subtitles/` 等多级子目录，智能关联提取同名外挂字幕，免除手动拖拽加载繁琐步骤。
- **纯透明悬浮播控栏 (Minimal Transparent Floating HUD)**:
  彻底移除原有底部深灰不透明方框底板，升级为直接融入视频画面的悬浮控制胶囊，观影视觉更加通透无遮挡。
- **DTS / DTS-HD / Dolby TrueHD 软限幅防削顶下混 (Soft-Knee Limiter Downmix)**:
  双声道播放高规格多声道音轨时，自动应用平滑软限幅算法，杜绝音量过大引起的爆音与 DAC 硬件削顶失真。
- **标准音频播放独立解耦 (Decoupled Standard Audio Playback)**:
  免费版双击本地音频文件直接流畅播放，支持 1:1 视窗自由缩放吸附、播放列表抽屉快捷唤出与画布空白处点击播放/暂停，不绑定 Pro 音乐模式，保持轻巧纯粹。
- **系统级细节优化与社区 Issue 闭环**:
  - 多屏扩展全屏防光标唤醒 (ISSUE-021)；
  - 竖屏短视频关闭后视窗横屏居中复位 (ISSUE-022)；
  - 冷启动桌面平铺隔离 (ISSUE-018)；
  - 优化起手快甩拖拽平滑跟手度 (ISSUE-017)。

## 安装与分发说明 / Installation & Distribution

1. **下载与挂载**:
   从官方网站直接下载 `SilkPlayer-2.0.0-universal.dmg`（采用 Apple 原生 LZMA 格式压缩，体积仅 22.8 MiB，由 Cloudflare 边缘 CDN 直连加速交付）；
2. **拖拽安装**:
   打开磁盘镜像，将 `SilkPlayer.app` 拖入旁边的 `Applications`（应用程序）文件夹中；
3. **初次打开安全提示 (Gatekeeper)**:
   若 macOS 提示未验证开发者或隔离警告，在「应用程序」目录中按住键盘 `Control` 键并点击应用，选择「打开」即可永久授权信任；镜像内亦随附《安装指南_Installation_Guide.txt》供查阅参考。
