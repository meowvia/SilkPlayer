## 二、 专项审计：测试套件“自证式假阳性”与构建链路偏差（重点审阅）

本节针对项目中宣称的“**52 项回归测试 / 480 项断言 100% 绿灯、0 编译警告**”进行逐行拆解与实测复核，请维护智能体（Antigravity）重点核查并纠偏：

### 2.1 `PlaylistTests.swift` 存在“测试局部函数而非生产代码”的假阳性问题
在 [`Tests/SilkPlayerTests/PlaylistTests.swift`](file:///Volumes/2T/Projects/SilkPlayer/SilkPlayer/Tests/SilkPlayerTests/PlaylistTests.swift) 中，有多个测试编号**并未调用生产模块的方法**，而是在测试函数内部编写了局部函数或局部公式自己测自己，甚至出现了“测试断言通过，但生产代码根本没写该功能”的脱节现象：

1. **Test 10（L142~162，`3-Second Rewind Threshold for Previous Track`）—— 生产代码未实现**：
   - 测试内部定义了局部函数：
     ```swift
     func simulatePreviousAction(currentPos: Double, mgr: PlaylistManager) -> (action: String, targetItem: PlaylistItem?) {
         if currentPos > 3.0 { return ("rewind", mgr.currentItem) }
         else { return ("previousTrack", mgr.moveToPrevious()) }
     }
     ```
   - **真实生产代码核查**：在 [`Sources/SilkPlayer/App/AppShellView.swift`](file:///Volumes/2T/Projects/SilkPlayer/SilkPlayer/Sources/SilkPlayer/App/AppShellView.swift) 的 `playPrevious()`（L265~272）中：
     ```swift
     private func playPrevious() {
         if let prevItem = playlistManager.moveToPrevious() {
             playPlaylistItem(prevItem)
         } else {
             player.seek(to: 0.0)
             player.play()
         }
     }
     ```
     生产代码**根本没有检查 `player.currentTime > 3.0`**，只要 `hasPrevious` 为 `true`（非第一首），无论当前播放到第几分钟，点击上一首都会直接切回上一集，而不会重头播放当前曲目。

2. **Test 26（L419~429，`Verify Magnetic Snapping Threshold Logic`）—— 生产代码未实现**：
   - 测试内部定义了局部函数 `func testSnap(_ t: Double) -> Double` 测试 `1.2%`（`max(2.0, totalDur * 0.012)`）章节磁吸逻辑并断言通过。
   - **真实生产代码核查**：在 [`Sources/SilkPlayer/HUD/PlayerScrubberView.swift`](file:///Volumes/2T/Projects/SilkPlayer/SilkPlayer/Sources/SilkPlayer/HUD/PlayerScrubberView.swift) 中，虽然注释写了 `// MARK: - Isolated Progress Section with Millisecond Magnetic Snap`，但在 `DragGesture`（L255~290）与 `fraction(for:)` 中**没有任何章节磁吸计算代码**。

3. **Test 48（L1515~1529，`Pure Audio Mode Detection & Discrete Artwork Invariants`）—— 公式已过期脱节**：
   - 测试中手写局部变量 `let computedCard = min(300, max(180, min(fullScreenWidth * 0.48, fullScreenHeight * 0.46)))` 并断言 `computedCard == 300`。
   - **真实生产代码核查**：[`Sources/SilkPlayer/Player/AudioArtworkView.swift`](file:///Volumes/2T/Projects/SilkPlayer/SilkPlayer/Sources/SilkPlayer/Player/AudioArtworkView.swift)（L29）实际使用的是 `let coverCardSize = min(360, min(availableW * 0.52, safeH * 0.52))`。因为测试没有调用生产视图或共享几何函数，生产代码改了之后测试依然“假绿灯”。

4. **Test 8（L116）、Test 44（L1324）、Test 49（L1532）、Test 52（L1580）—— 均为局部函数自测**：
   - `computeResumePosition(for:)`、`mockFindBest(in:target:)`、`simulateMetalDraw(activePipeline:)`、`determineTier(width:isFullscreen:)` 均是在测试文件内部定义的局部函数，完全不具备对生产代码的回归保护能力。
