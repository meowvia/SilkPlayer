## 2. 功能更新归档

### 2.1 Universal 通用双架构镜像发布
- 单个安装包原生内嵌 `arm64` 与 `x86_64` 双架构切片，同时支持 Apple Silicon (M1-M4) 与 Intel 64 位芯片机型，免 Rosetta 2 转译直接原生运行；
- 构建脚本 `package_app.sh` 实现了多架构编译、fat framework/binary 合并、签名完整性与内部挂载二次依赖审计。

### 2.2 播控栏交互式音量微调与起播防破音保护 (提案 015 销项)
- **动态音量图标与微型滑块**: 播控栏音量按钮升级为动态图标，悬停平滑展开精度滑块，支持细粒度音量调节；
- **起播平滑防破音保护**: 引入起播平滑渐变算法，在视频起播与大跨度调音时实施瞬态过渡，消除杂音与破音冲击。

### 2.3 批量剧集全局自然语义排序 (提案 016 销项)
- **多层目录递归扫描**: 支持多层文件夹递归扫描与全量媒体文件扁平化提取；
- **自然语义排序算法**: 引入自然语义排序算法（`MediaFilenameSanitizer.compareNaturalOrder`），智能识别剧集编号与命名标记（如 `S01E01`、`EP02` 等），解决多集剧集导入时的乱序错位。

## 3. 性能优化归档 (提案 017 销项)

### 3.1 4K 高码率视频显存与管线降耗
- **常驻缓存上限裁剪**: 优化高码率连续播放缓存策略，将常驻帧缓存上限裁剪至 3 帧，大幅降低 4K 10-bit 片源常驻显存开销；
- **条件变量同步消除忙等待**: 解复用管线引入 `NSCondition` 条件变量同步机制，消除高频 `usleep` 轮询忙等待引起的 CPU 损耗；
- **待机空载降耗**: 空载与暂停状态下自动暂停动态发光重绘，消除空转能耗。

### 3.2 纯音频渲染能耗轻量化
- **移除实时高斯模糊**: 重构纯音频唱片与光晕渲染管线，移除实时高斯模糊计算，显著降低纯音频播放时的 CPU 负载；
- **采样降频与阈值过滤**: 频谱采样与节拍定时器优化为 20Hz 并集成动态阈值死区过滤，大幅降低主线程重绘频率。

## 4. 缺陷修复归档 (Issues Closed in 1.5.0)

### 4.1 ISSUE-011: 音频模式下手动调整播放窗口尺寸边框抖动
- **根因**: 音频模式等比缩放约束与系统自由调整尺寸发生冲突产生高频振荡；
- **解决**: 规范化等比计算并设置稳定边界，手拉尺寸平滑流畅。

### 4.2 ISSUE-012: 置顶图钉层级导致全屏请求死锁
- **根因**: 开启置顶时剥离了全屏主能力集，导致全屏转场请求被系统静默抛弃；
- **解决**: 置顶仅提升窗口层级为 `.floating`，严格保留全屏能力集；进入全屏时弹出防冲突 OSD 提示。

### 4.3 ISSUE-013: 铺满最大化模式下按 Esc 键误退出播放
- **根因**: 按键响应链缺失铺满最大化（Maximized）分支，Esc 穿透至退出播放回调；
- **解决**: 建立四级按键响应链，最大化状态下按 Esc 准确缩回原普通尺寸，播放不中断。

### 4.4 系统行为确认: macOS 平铺分屏 (Window Tiling) 拖拽解除与还原
- 确认拖拽分屏窗口离开边缘恢复自由尺寸属于 macOS WindowServer 原生标准规范，非缺陷。
